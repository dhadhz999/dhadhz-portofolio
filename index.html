GitHub Pages & Vercel Quick Guide

Single-file hosting with zero build tools required

Step 1: Upload index.html to GitHub

Create a new public repository on GitHub (e.g., dhadhu-portfolio), click Add file → Upload files, and upload this single index.html file.

Step 2: Turn on GitHub Pages (or Vercel)

In your GitHub repo, go to Settings → Pages. Under Branch, select main and click Save. Your site will be live in 60 seconds! (Or import the repo on vercel.com for a .vercel.app domain).

Step 3: Two Easy Ways to Edit Later
  • Visual Browser Way: Click the Customize button on your live website, add or edit projects, click Download Updated index.html, and upload it to GitHub.
  • Direct GitHub Code Way: Open index.html on GitHub, press the . (period) key on your keyboard to open the web editor, and edit the PORTFOLIO_DATA object right at the top of the <script> tag.
